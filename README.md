⚡ Assistant Pédagogique Intelligent pour Professeurs, Formateurs... 

Bienvenue sur le code source de l'Assistant Pédagogique Intelligent.
Cette application web a été conçue pour aider  à générer rapidement des trames de cours sur mesure, minutées et conformes aux référentiels de diplômes.

🎯 Fonctionnalités principales

Génération sur mesure : Adaptation au public cible (CAP, BTS, etc.) et à la durée de la séance.

Contextualisation locale : Choix du lieu et du type d'entreprise pour ancrer le scénario dans la réalité des apprenants.

Conformité stricte : Intégration directe des compétences du référentiel officiel.

Fiche pédagogique complète : Déduction automatique des prérequis et des savoirs associés.

Exportation : Téléchargement du cours généré au format texte/markdown.

🛠️ Technologies utilisées

Interface Web : Streamlit (Python)

Intelligence Artificielle : Google Gemini (Modèle 2.5 Flash)
